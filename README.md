# AICA — Ambient AI for Medical Consultations

> Built at the **Harvard Health Hackathon 2026**, co-organized with Medifé and Sanatorio Finochietto.

AICA is an ambient AI system designed to reduce administrative burden on physicians by automating clinical documentation during medical consultations — and delivering structured summaries directly to patients.

---

## Monorepo Structure

```
aica/
├── aica-app/         # Real-time transcription agent + clinical summary engine
└── aica-paciente/    # Patient-facing mobile app
```

---

## aica-app

The core AI agent. Listens to the consultation in real time, transcribes the conversation, and generates a structured clinical summary with:

- Diagnosis and therapeutic recommendations
- Medication schedules
- Follow-up instructions

**Stack:** JavaScript · Node.js · Claude API (Anthropic)

### Run

```bash
cd aica-app
npm install
npm start
```

---

## aica-paciente

Mobile app for patients. Receives the summary generated by `aica-app` and presents:

- Consultation summary
- Medication schedule
- PDF prescription
- Calendar follow-up reminders

**Stack:** JavaScript · React Native · Expo

### Run

```bash
cd aica-paciente
npm install
npx expo start
```

---

## Motivation

EHR documentation is one of the leading causes of physician burnout. AICA removes the physician from the keyboard during consultations, letting them focus entirely on the patient — while ensuring the patient leaves with clear, structured information about their care.
